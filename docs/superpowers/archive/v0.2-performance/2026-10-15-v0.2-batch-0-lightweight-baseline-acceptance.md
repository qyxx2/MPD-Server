这记录真实 NAS/MPD 加浏览器 DOM 的基线，但不包含用户设备、WAN/IPv6 RTT、移动端渲染或可听 DAC 延迟。SSH 仅编排和取证，不能把其网络往返算入 HTTP。

每种规模建立一次绑定有效的 8/400 首队列；每轮按 Next → Previous → Pause → Resume → song 立即播放 → append 一首执行，重复三轮。实际规模按 API 语义流转，末次 append 恢复每轮起始规模；逐例记录实际 current+pending、Played 数，不能把每例都称为恰好 8/400 首。准备、UNBOUND 修复、AutoPlay、重试不纳入稳定态统计。

四段时刻全部来自**同一页面 `performance.now()`**：capture click、调用 fetch、mutation JSON 完整解析返回、合格权威状态到达、DOM 状态与按钮恢复。保留 headers 时刻、HTTP/WS 原始事件顺序及请求诊断 ID。HTTP 指完整 JSON body 可用，非仅响应头；WS invalidate 单独记录，不冒充权威观察。页面路由切换和歌曲菜单打开在计时前完成。

合格状态要求同 epoch、sequence 超过操作前、fresh/actual_fresh、CONFIRMED、matches_current、有 control target、预期歌曲及实际 transport 状态；切歌/暂停/继续还要求业务 updated_at 已推进，observed_at 覆盖该 updated_at。append 要求 Queue revision 推进并出现新 occurrence，保留原 current。控制页 DOM 要求目标标题、主按钮标签/可用性和 aria-busy=false；Library 两操作检查本次任务通知 success、busy 清除以及已存在菜单无 disabled 项；菜单在点击后关闭，未独立重开菜单测其最早可用时刻。DOM 是合格权威观察与界面就绪的联合门槛，由浏览器 MutationObserver/状态返回钩子检查，不是屏幕 paint 或 DAC 出声。Library 的任务/按钮可能已提前恢复；此处第 4 段表示观察到达后的额外就绪等待，不宣称定位了按钮最早恢复瞬间。

若观察先于 HTTP body，保留真实顺序，HTTP 后额外等待取 0；观察→DOM 仍按实际时刻计算，可能包含尚待 HTTP 的部分。服务端 DB/MPD 锁等待独立用进程单调时钟、通过诊断 ID 关联；不与浏览器时间戳相减。完整 sample 只统计该 mutation 内，后台另计；嵌套 inclusive 阶段不累加。
