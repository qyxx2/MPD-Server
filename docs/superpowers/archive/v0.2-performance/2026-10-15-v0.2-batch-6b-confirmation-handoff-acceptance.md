## 样本来源与降级

| 入口 | 可交接的最终样本 |
|---|---|
| start_track、play_context、play_now、play_song_now、Next、Previous | 最后一次 `_confirm_preserved_state()` 内 `_confirm_current_occurrence()` 的真实完整读取 |
| play_next、append、reorder、clear、删除 pending | 保留 current 的最终完整 occurrence 确认读取 |
| 删除 current 且有播放中的 successor | successor 全部控制完成后的 `_confirm_current_occurrence()` 读取；之后只有业务/History 保存 |
| Resume、带 target 的 Seek | `_confirm_control_transport()` 在控制后验证 state/position 的真实完整读取 |
| Pause、无 target 的 Seek、Stop、停止态或无合格最终样本 | 保留 B6-A，不增加完整读取来统一接口 |
| 自然接纳、AutoPlay/refill、异常恢复 | 保持现有保护流程；不将 B7 检查样本接入用户操作交接 |

候选只在当前原子调用内存在，不从 RecoveryJournal 的历史 sync_sample 或 receipt 推断新鲜事实。记录真实完整读取开始时间；最终调用返回前，在同一事务内再次验证完整 occurrence 映射、队列 revision 对应的 binding、Player 实例、service/connection epoch、partition、playlist version、实际 current/state、模式、error 和样本年龄。缺 binding、quarantine、不匹配或过旧时不交接。

合格样本沿原 Observation/Coordinator/ControlTarget 事务可见性机制公开；generation 更新拒绝操作前开始的旧观察。外层回滚、SQLite commit 失败、取消均恢复旧观察并撤销新 token；外部控制不能回滚时，旧 token 的不可逆失效继续保留。

提交同步钩子只检查交接身份、token 与 freshness；已覆盖需求不再无条件唤醒 Observer。若外层事务拖延至样本过期，保留原采样时间并唤醒 B6-A。钩子没有网络 I/O，不等待后台观察；周期兜底及已经在途的观察不取消。

## 明确的 DTO 与收敛合同调整

同步更新[架构规格的 Observation 合同](../../specs/2026-09-25-system-and-development-architecture-design.md)：新增 nullable `playback_observation.covered_playback_updated_at`，表达真实匹配样本覆盖的业务状态水位。旧服务缺字段按 null 解码。

`observed_at` 保留读取开始时间，不改写为业务更新时间或提交时间。前端 Seek 继续要求 fresh、有效绑定和同一 control identity；当覆盖水位与当前业务 `updated_at` 及本次回执的原始时间字符串精确相等时可完成收敛。旧服务的采样时间规则仍保留，比较时保留微秒，避免同一毫秒内先后提交混配。HTTP/WS 先后顺序不影响判断。

Queue 业务内容与 History 不变的操作，现在可同时使确认观察变更：WS invalidation 包含 playback 域，业务 Publisher 仍只报告原业务 Queue delta。已提交观察的 token 在失败控制后被撤销时，可以发布安全失效通知；这不代表失败操作成功或 Stop generation 已提交。相关回归改为验证这些明确合同，没有移除业务、回滚、幂等或完整映射断言。

公共 DTO golden 由原生成器重建，只增加覆盖字段及相应实际提交 sequence；Task9 时间归一化包含新水位，保留完整资源/回执比较。
